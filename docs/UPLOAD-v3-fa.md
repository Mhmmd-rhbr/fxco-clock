# راهنمای آپلود نسخه ۳ ساعت مالی آریامرکس

تاریخ آماده‌سازی: ۱۶ نوامبر ۲۰۲۶  
نسخه بسته: `3.0.0`؛ Manifest V3

## فایل اصلی

فایل `dist/aryamerx-financial-clock-3.0.0.zip` را مستقیماً آپلود کنید. آن را دوباره داخل پوشه یا ZIP دیگری قرار ندهید. فایل manifest در ریشه آرشیو است و آزمون‌ها، اسناد توسعه و فایل‌های اضافی وارد بسته نمی‌شوند.

## مراحل ارسال به فروشگاه

1. [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole) را باز کنید و آیتم **موجود** AryamerX Financial Clock با شناسه `kfckocecbefclalkmjdkkpaoehicbede` را انتخاب کنید. برای آپدیت، آیتم تازه نسازید.
2. در بخش Package، گزینه بارگذاری بسته جدید را انتخاب و ZIP نسخه ۳ را آپلود کنید. نسخه باید از بالاترین نسخه قبلی همان آیتم بیشتر باشد؛ نسخه‌های پیش‌نویس داشبورد نیز در این مقایسه مهم‌اند.
3. عنوان، توضیح کوتاه و توضیحات اصلی را از [متن آماده فروشگاه](STORE-LISTING-v3.md) بردارید. توضیحات «هدف واحد» و دلایل مجوزهای همان فایل نیز آماده‌اند.
4. در بخش حریم خصوصی، رفتار واقعی نسخه را ثبت کنید: ذخیره محلی برنامه‌ها و تنظیمات، بدون ارسال به سرور و بدون تحلیل‌گر رفتار؛ اعلان اختیاری است. متن کامل آماده در [PRIVACY.md](../PRIVACY.md) قرار دارد.
5. برای فیلد آدرس سیاست حریم خصوصی، همین متن را در یک آدرس HTTPS پایدار در سایت AryamerX منتشر یا به صفحه موجود اضافه کنید و همان آدرس واقعی را وارد کنید. سیاست داخل ZIP به‌تنهایی جای آدرس عمومی این فیلد را نمی‌گیرد. این کار در سایت هنوز انجام نشده است.
6. اسکرین‌شات‌ها و اطلاعات پشتیبانی آیتم موجود را بازبینی کنید؛ تصویر و توضیحات باید رفتار نسخه جدید را نشان دهند. پیش‌نمایش‌های تهیه‌شده از رابط در گزارش انتشار معرفی شده‌اند؛ برای ابعاد اجباری تصویر، از الزامات همان فرم استفاده کنید.
7. پس از تکمیل فیلدهای لازم، ارسال برای بررسی گوگل را انجام دهید. انتشار عمومی پس از بررسی و طبق تنظیمات همان آیتم انجام می‌شود؛ ساخت ZIP به معنی انتشار نیست.

## مجوزها

| مجوز | کاربرد |
|---|---|
| `storage` | نگهداری تنظیمات، برنامه‌ها، یادداشت‌ها و وضعیت یادآور روی دستگاه؛ خواندن یک‌باره تنظیمات قدیمی برای مهاجرت |
| `alarms` | زمان‌بندی بررسی یادآورها و نشانگر آیکن هنگام بسته‌بودن پنجره |
| `sidePanel` | نمایش برنامه‌ریز در پنل کناری Chrome |
| `notifications` اختیاری | فقط هنگام فعال‌کردن یادآور توسط کاربر درخواست می‌شود |

افزونه host permission، دسترسی به محتوای سایت‌ها، تاریخچه، کوکی یا حساب بروکر ندارد. هیچ API یا کد اجرایی راه دور مصرف نمی‌شود. فونت و رابط به اینترنت متکی نیستند.

## بررسی بعد از انتشار

طبق تصمیم کاربر، نمایش اعلان واقعی سیستم‌عامل بعد از انتشار آزموده می‌شود. منطق زمان‌بندی، جلوگیری از تکرار، تعویق و مجوز اختیاری در آزمون‌های خودکار بررسی شده؛ نمایش واقعی اعلان در macOS یا Windows هنوز تأیید نشده است.

روی نسخه نصب‌شده از فروشگاه این موارد بررسی شوند: بازشدن پنجره سریع و صفحه کامل، بازشدن پنل کناری، حفظ تنظیمات بعد از راه‌اندازی مجدد Chrome، نشانگر آیکن، درخواست اختیاری اعلان، یادآور نزدیک همراه با تعویق، و رفتار پس از sleep/wake. برای تست سریع یک برنامه چند دقیقه بعد بسازید و ساعت سکوت و زمان پیش‌آگاهی را طوری انتخاب کنید که زمان ارسال خارج از بازه سکوت باشد و هنوز نگذشته باشد.

بسته نهایی برای بارگذاری آماده است؛ آپلود، تکمیل آدرس عمومی سیاست و ارسال برای بررسی گوگل در این پروژه انجام نشده‌اند.
